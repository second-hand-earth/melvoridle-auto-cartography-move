# Melvor Idle Auto Cartography Move

A mod for Melvor Idle that automatically moves your character to the cartography map node corresponding to your current active skill.

ex. Moves to The Secret Glaical Hoard when crafting potions with Herblore

This mod does not reduce travel costs or use travel-reducing items such as the Compass or Cape.

Does not move the player for Combat skills.

Unknown behavior if the user does not have the relevant cartography map POI yet. 

[View the mod on mod.io](https://mod.io/g/melvoridle/m/auto-cartography-move)
